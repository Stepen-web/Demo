Hello Chatkhil PWA
==================
This project is a PWA version of the social service app with Admin Panel (Firebase).
Steps:
1. Put your uploaded file as src/social-service-pwa.tsx
2. Fill src/firebaseConfig.ts with your Firebase project config
3. Run:
   npm install
   npm run build
4. Deploy build/ to Netlify/Vercel or run locally with:
   npm run serve
